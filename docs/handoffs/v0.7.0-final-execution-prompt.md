signature of a budget too small to finish a call. The environment's own oracle
clears the identical settings 8/8 at 64, 128 and 256 tokens per turn and at both
difficulties. The harness is sound; the models never entered the tool protocol.

`training_task.environment: tool_policy`, `strict_task_success_rate: 1.0`,
`parse_valid_tool_call_rate: 1.0`. Real tool-protocol competence — for a
different environment's tool set. JSONNav has its own tools and state space, so
the anchor itself at zero continuation updates scores 0/64.

The retained-utility endpoint measured a competence neither lineage ever had.
**That is a study-design finding, not a reason to change the endpoint.**
